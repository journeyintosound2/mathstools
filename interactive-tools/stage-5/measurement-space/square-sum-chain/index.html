Number Sum Chain
The challengetap to hide

Arrange the numbers 1 to 15 in a single line so that every pair of neighbours adds to a square number.

Use the workspace to think it through however you like — move the tiles around, join them up, write on it. When you are ready, drag tiles into the 15 spaces and press Check answer.

Start with 15. Then see which bigger ones work — and which can’t.

Every number is a dot. Two dots are joined when they add to a square number. A chain is a path along the lines that visits every dot exactly once.

    How it works

    Make every pair of neighbours add to a square number

    1. 1
      Use every number from 1 to 15, each one exactly once.
    2. 2
      Put them in one line.
    3. 3
      Every pair of neighbours must add to a square number.

    The example uses numbers you won’t be using, on purpose — it doesn’t give anything away.
