Times Table Chart

The chart

The first number is always the number of rows (down the side); the second is how many are in each row (along the top).

Steps

Build the rectangle and Find it finish by flipping the fact over the diagonal: 4 × 6 and 6 × 4 are the same squares.

On screen

The numbers stay on the squares of the rectangle, very faint, and each step makes the ones that matter dark. Off, the squares start empty, so the answer can’t be read early.
