One-Step Equations – Double Number Line
How it starts

On: start from the whole equation as one point and make the same move on both lines, as in the Multi-Step tool, with the working beside it. Off: build the expression from x first (explore). Key E.

New questions

Now and then the number comes first (5 + x = 12) or the sides are swapped (12 = x + 5). The picture is the same.

Steps

Adds a step where x is still ? so the class can predict.

A last step puts the answer back in: 7 + 5 = 12 ✓

On the number line

Orange is what was done to x. Purple is the move that undoes it.

The same move takes the top line back to x and the bottom line to the answer.
