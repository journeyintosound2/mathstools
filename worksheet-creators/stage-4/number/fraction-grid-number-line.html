Fraction Grid to Number Line — Worksheet Generator

Printable A4 worksheets built from the Fraction Grid to Number Line teaching tool. Every question puts the area model and the number line side by side, so the fraction has to travel between them — it is never just a conversion to recite. Questions are grouped into lettered sections with one instruction each, and the number line runs the full width of the page so a point can actually be marked accurately. The ladder raises the demand on the line while the grid stays: Sweet's line is cut into the same parts as the grid, Mild's into tenths, Medium's into a different unit again, and Spicy gives only 0, ½ and 1.

The paper

Sections

Each kind becomes its own lettered section, so the instruction is written once and the questions inside it climb the level ladder.

Options

The reasoning prompt sits in a box at the foot of each page — a misconception to argue with, using the line as the evidence. It is the item worth marking properly.
