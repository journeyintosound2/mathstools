Multiplying Fractions (Area Model) — Worksheet Generator

Printable A4 worksheets from the Multiplying Fractions — Area Model teaching tool. Each section hands over a different amount of the model — shade one, finish one, read one backwards, partition a blank one, or drop the picture entirely. Worksheet language prints every instruction bilingually for EAL/D students; the maths stays in Western numerals.

The scaffold fades left to right. Shade gives a square already cut both ways. Finish gives only the second fraction, cut and shaded. Read runs backwards: a shaded model, write the multiplication. No partitions is a blank square to cut up. No model is plain fluency practice. Each section climbs its own spice ladder.

Options

Simplest form asks for the answer and its simplest form on the same line — nothing on the page gives away which ones simplify. The reasoning prompt is a misconception to argue with, using a square as the evidence.
