Counting Strategies for Linear Relationships — Worksheet Generator

Printable A4 worksheets from the Counting Strategies teaching tool. Every question starts from an instruction like “Start at 5, count up by 3s” — then the student writes the sequence, fills a table, plots it, and writes it as y = 5 + 3x. Later sections run it backwards and argue about mistakes.

The paper

Sections — the scaffold fades from A to F

The sections follow the lesson: count it out, put it in a table and plot it, write it as an equation, then go backwards from an equation or a graph, find the mistake in someone else’s work, and use the equation to go further than counting can.

Options

With Number the axes off, the graphs print as blank grids and choosing the scale is part of the question (the key shows one scale that works). Graphs use the same idea as the tool’s auto-scale: each axis is scaled to fit its own numbers.
