# Taxed by the King — MMT colours, offline mode, recording sheet (2026-11-17)

File: `games/taxed-by-the-king.html` (same URL). Inspired by Toby Russo / SURF Maths, *The King's Tax*.

## Colours
Now matches the other MMT games: navy→blue header, blue primary buttons, MMT page background, blue card backs and rule buttons. Playing cards keep red/black and the King's tax stamp stays red.

## Offline class game
Third option on the start menu ("Offline class game — No devices") and on the home screen.
- No Firebase, no student devices, nothing saved. Firebase now loads only when an online mode is picked, so offline mode works on a blocked or absent network.
- The teacher's screen runs the deck with the same card rules as the online game.
- Students stand at the start of each round, sit down to bank, and record everything on the printed sheet.
- Setup options: students work out the round total (shows "?" until **Reveal**, on by default) · new card rules between rounds (teacher enters the rank and rule chosen by the student who banked most) · probability panel · Joker negatives.
- Buttons: Start Round · Turn Card (Space) · Reveal total (R) · Everyone has banked.
- **Round log** (side panel): every running total for every round, used as the answer key for checking sheets.
- End screen: steps to find the winner and a discussion prompt.

## Tools ▾ (offline mode only)
- **Print recording sheet** — preview + options, then print.
- **How offline mode works** — the eight steps.

## The recording sheet (A4 landscape)
- Header: title, Name / Class / Date.
- Card values strip: A = $1, 2–10 = their number, J = +$20, Q = double it, Joker = −$20 (wording follows the negatives setting), K = tax (still standing → $0), sit down = bank.
- One-line instructions.
- Table: one row per round. A box per card (the card on top, the new running total below) · **Banked this round** · **Total bank** (= the total bank above + banked).
- Worked example row (5♥, 8♣, Q♦, J♠ → 5, 13, 26, 46; banked $46).
- Footer: New card rules (Card [ ] now ____ ×3) · "When did you bank — and why?" · My final bank.
- Options (remembered): rounds 6 or 8 (one page) / 12 or 16 (two pages); boxes per round 8/10/12; card space; example row; card values strip; rules box; reflection.
