      Division with a Ratio Table

      MA3-MR-01

      Four sections that build on each other: finish a table already begun, build one from the single row every table starts with, plot the rows on a grid beside the table, and word problems that ask how many groups fit. The goal row states the total and leaves the groups blank, so the unknown is where a ratio table puts it. Optional grid on every question, check sentence, and an answer key that shows a route through the table rather than the answer alone. Trilingual.

      Fraction of an Amount — Divide, Then Multiply

      MA3-RQF-02

      The printable partner of the teaching tool. The bar comes off one step at a time: fill a bar already cut, divide then multiply on a shaded bar, cut and shade your own, then the notation carries it — write it five ways, true or false, spot the mistake, word problems, and build the whole back from a part. Levels set the size of one part; answer key fills in every bar.

      Division by Grouping

      MA3-MR-01

      The bubbles are printed on the page, so a student shares out a chunk at a time exactly as the class did on the board — and the table beside them turns those chunks into the written method. Five sections that take the scaffold off one layer at a time: finish a round that has been started, share it out from empty, the table with no bubbles at all, remainders, then word problems. Answer key shows the rounds, not just the answer.

      Division with a Ratio Table

      MA3-MR-01

      Every question starts with one row: 1 group, and what one group is worth. A new row is entered the way a coordinate is — type the groups, press Enter, then type the total for those groups. Get the pair right and it locks in; get it wrong and the whole pair shakes and goes, because half a row is not a row. Rows can also be built from rows already there: ×10, halve it, add two together, take one off another — and the move is flashed on both columns, which is the whole claim a ratio table makes. When a row lands exactly on the number being divided, the left column is the answer: 270 ÷ 15 = 18. Optional Cartesian plane plots every row as a point, so a Stage 3 table and a Stage 4 straight line through the origin are the same picture.
